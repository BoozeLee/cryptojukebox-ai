# Attribution and relicensing ledger

No private Dream Script Engine source has been imported into this repository.

The initial relicensing audit is recorded in
[docs/relicensing-audit.md](docs/relicensing-audit.md). CryptoJukebox uses a
clean-room Dream Script mapper until an auditable source and dependency chain
is available.

Any future imported source must record its original repository, audited commit,
authorship confirmation, dependency license review, relicensing decision, and
the public file that contains the resulting code.
