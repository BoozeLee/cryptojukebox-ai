# CryptoJukebox

CryptoJukebox turns a local, user-authorized audio file into a downloadable
creative intake: dream seeds, idea prompts, symbolic motifs, and prompt
fragments derived from deterministic audio features.

The first release processes files entirely in the browser. Audio is not
uploaded, stored, or sent to an external service.

## Status

The public release is under construction. Cryptocurrency payments, wallets,
third-party music/video URLs, accounts, analytics, and hosted processing are
out of scope for the first version.

## Safety and scope

CryptoJukebox produces creative suggestions. It does not infer facts about a
listener, artist, mental state, consciousness, health, or therapy. Only select
audio that you own or are authorized to process.
